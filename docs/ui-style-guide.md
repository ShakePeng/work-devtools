# UI 风格规范：Work DevTools 工作台风格

这份规范用于让 Work DevTools 内的 Cookie Injector 及后续工具保持同一套视觉和交互语言。目标是做出**克制、清晰、偏数据管理的工作台**，而不是营销页或大屏。

适用场景：浏览器扩展 Popup、后台管理页、配置页、数据管理工具。示例基于 Vue + Tailwind，但视觉规则不依赖具体框架。

## 一句话原则

> 大面积使用 Slate 中性色；Sky 只承担主操作和选中态；颜色用于表达业务语义；层级依靠留白、边框和轻阴影，不依靠渐变和重投影。

## 视觉基调

- **浅色背景**：页面使用 `slate-100/80`，内容面使用白色。
- **深色背景**：页面使用 `slate-950`，内容面使用 `slate-900`。
- **边框优先**：容器优先用 `border` 划分，阴影只使用 `shadow-sm`；弹窗和抽屉才使用 `shadow-2xl`。
- **圆角分层**：页面级卡片 `rounded-2xl`，内部信息块 `rounded-xl`，按钮和输入框 `rounded-lg`。
- **图标辅助文字**：使用 14–20px 线性图标，不用表情符号充当正式 UI 图标。
- **避免装饰化设计**：不使用大面积渐变、玻璃拟态、厚重阴影、彩色背景墙或超大标题。

## 设计令牌

### 颜色

| 角色 | 浅色模式 | 深色模式 | 用途 |
|---|---|---|---|
| 页面背景 | `slate-100/80` | `slate-950` | 整体画布 |
| 主内容面 | `white` | `slate-900` | 卡片、侧栏、弹窗 |
| 次级内容面 | `slate-50` | `slate-950/50` | 卡片内分组、只读信息 |
| 常规边框 | `slate-200` | `slate-800` | 卡片、输入框、分隔线 |
| 主操作 / 选中 | `sky-600` | `sky-400` | 保存、添加、当前导航、焦点 |
| 正向状态 | `emerald-500/600` | `emerald-300/400` | 成功、已启用、完成 |
| 提醒状态 | `amber-500/600` | `amber-300/400` | 注意、Cookie 语义、待确认 |
| Bridge 语义 | `violet-500/600` | `violet-300/400` | Bridge、运行时 Mock |
| 危险状态 | `red-500/600` | `red-300/400` | 删除、失败、不可逆操作 |
| 主文字 | `slate-800` | `slate-100` | 标题、正文 |
| 次级文字 | `slate-500` | `slate-400` | 说明、辅助信息 |
| 元信息 | `slate-400` | `slate-500` | 标签、时间、统计说明 |

### 字体与密度

| 内容 | 建议样式 |
|---|---|
| 页面标题 | `text-xl font-semibold` |
| 区块标题 | `text-base font-semibold` 或 `text-sm font-semibold` |
| 正文 / 表单 | `text-sm` |
| 列表辅助文字 | `text-xs` |
| 眉标 / 元标签 | `text-[10px] font-semibold uppercase tracking-[0.12em]` |
| 数值统计 | `text-sm font-semibold tabular-nums` |
| JSON / Cookie 值 | `font-mono text-xs leading-6` |

正文保持 14px 左右，信息密集区域可以降到 12px，但不要低于 10px。标题使用 `font-semibold`，避免粗黑体和过多不同字重。

### 尺寸与间距

- 基础间距以 `4px` 为单位：`gap-1/2/3/4/5/6` 分别对应 4/8/12/16/20/24px。
- 管理页主内容：`p-5 lg:p-7`。
- 卡片内边距：普通卡片 `p-4`，模块卡片 `p-6`。
- 页面标题和内容之间：`mb-6`。
- 页面级纵向相邻的独立模块：`mb-2` 或父容器 `space-y-2`，即 `8px`；例如功能 Tab 与内容、危险操作与其上方卡片。
- 响应式并列模块保留桌面横向间距，并将窄屏堆叠间距设为 `8px`，例如 `gap-x-5 gap-y-2`。此规则不用于卡片内部、表单字段或列表行。
- 表单行间距：`space-y-4` 或 `space-y-5`。
- Popup 固定工作区：宽 `460px`、高 `600px`；若业务不同可调整高度，但保持紧凑的单列信息密度。

## 页面骨架

### 管理页

桌面端采用固定左侧导航 + 可滚动主内容区：

```text
┌──────────── 248px 导航 ────────────┬──────────── 主内容 ────────────┐
│ 品牌区（高 76px）                  │ 页面标题 / 操作               │
│ 管理工具导航                       │ ┌──── Surface / 内容模块 ───┐ │
│                                    │ └──────────────────────────┘ │
│ 底部小型统计卡                     │                              │
└────────────────────────────────────┴──────────────────────────────┘
```

- 左栏宽度：`w-[248px]`，白色背景，右侧细边框。
- 品牌区：`h-[76px]`，包含 40px 深色方形图标、产品名、10–11px 英文眉标。
- 导航项：图标 32px 容器 + 标题 + 一行描述；选中态为 `sky-50` + `ring-1 ring-sky-100`，而不是强填充蓝色。
- 主内容：数据管理可 `p-3` 并占满高度；普通设置页使用 `p-5 lg:p-7`，允许纵向滚动。
- 左栏底部放 2–4 个紧凑统计值，帮助确认当前数据范围，不放大图表。

### 页面标题

每个独立设置页遵循下面结构：

```html
<header class="manager-page-header">
  <div class="flex items-start gap-3">
    <span class="manager-page-icon"><!-- 20px 图标 --></span>
    <div>
      <p class="manager-page-kicker">English Context</p>
      <h2 class="manager-page-title">中文页面标题</h2>
      <p class="manager-page-description">一句话解释页面职责和影响范围。</p>
    </div>
  </div>
  <!-- 右侧放页面级主操作或状态标签，最多 1–2 个 -->
</header>
```

标题区域的英文眉标只用于辅助定位，不要求翻译所有中文。描述必须讲清影响，例如“不会自动覆盖本地配置”，不要重复标题。

## 通用组件

### Surface 卡片

```html
<section class="rounded-2xl border border-slate-200 bg-white p-6 shadow-sm
  dark:border-slate-800 dark:bg-slate-900">
  <!-- 内容 -->
</section>
```

- 一个卡片只服务一个明确任务：配置、列表、预览、状态、确认。
- 卡片内再分组时用 `rounded-xl border bg-slate-50`，不要嵌套多个白色卡片。
- 页面内并列模块使用 `grid gap-x-5 gap-y-2`；不超过两层容器层级。

### 按钮

| 类型 | 推荐样式 | 使用规则 |
|---|---|---|
| 主按钮 | `bg-sky-600 text-white hover:bg-sky-700` | 每个操作区域最多一个，例如“保存连接” |
| 次按钮 | `border border-slate-200 bg-white text-slate-600` | 测试、取消、查看等非提交操作 |
| 幽灵按钮 | `text-slate-500 hover:bg-slate-100` | 行内工具、关闭、返回 |
| 危险按钮 | `bg-red-500 text-white` 或 `text-red-500 hover:bg-red-50` | 删除、覆盖等不可逆操作 |
| 图标按钮 | `h-7 w-7 rounded-md` | 必须有 `title` 或无障碍标签 |

- 标准按钮高度约 36–40px：`px-3 py-2` 或 `px-4 py-2.5`。
- 所有按钮保留 `disabled:opacity-50 disabled:cursor-not-allowed`。
- 加载中只替换文案或显示小型旋转图标，不改变按钮宽度。

### 表单

```html
<input class="w-full rounded-xl border border-slate-200 bg-slate-50 px-3 py-2.5 text-sm
  text-slate-800 outline-none ring-sky-500/30 transition
  focus:border-sky-400 focus:bg-white focus:ring-2
  dark:border-slate-700 dark:bg-slate-900 dark:text-slate-100" />
```

- 标签在上、控件在下；标签使用 `text-xs font-medium text-slate-500`。
- 默认使用 `slate-50` 输入背景，聚焦时变白，形成轻微但清晰的工作焦点。
- 复杂值（Cookie、JSON）使用等宽字体和 `leading-6`，并提供复制按钮。
- 校验错误紧贴相关区域，使用浅红背景 + 红色边框；错误要给出可执行原因。
- 必填项和保存条件由按钮禁用态表达，不靠红色星号堆砌。

### 状态标签、开关和业务色

- 状态标签采用浅色底 + 深色文字，不使用高饱和实心色块。
- Cookie 使用 Amber，Bridge 使用 Violet，成功使用 Emerald；同一页面不要再引入第四种业务色。
- 启用开关用 Emerald；禁用状态保持 Slate，避免把“关闭”误解为失败。
- 只读信息使用 `manager-surface-muted`，并配合锁图标或“只读”说明。

### 代码、JSON 与敏感值

- 结构化值预览使用深色代码面：`bg-slate-950 text-emerald-300 rounded-xl p-4 font-mono text-xs leading-6`。
- 默认不展示敏感值；展示时提供“查看 / 复制”明确动作。
- JSON 编辑区与只读预览在视觉上区分：编辑区有 focus ring，预览区没有。

### 弹窗、抽屉与确认

- 普通对话框：`max-w-[320px~440px] rounded-2xl shadow-2xl`。
- 复杂编辑：右侧抽屉，最大宽 `960px`，避免把多字段编辑塞入小弹窗。
- 遮罩使用 `bg-slate-950/45` 或 `bg-black/30`，需要时轻微 `backdrop-blur`。
- 删除确认必须包含危险图标、对象名称和明确动词，例如“确认删除”。
- 有未保存修改时才弹放弃确认；纯新增平台关闭不弹确认。

### Toast、空状态与错误状态

- Toast 固定右上角，最大宽 360–380px，3 秒自动消失，可手动关闭。
- Toast 图标放在 32px 浅色方块里，按成功/警告/失败使用 Emerald/Amber/Red。
- 空状态使用虚线边框、40–64px 浅色图标块和一句下一步指引；不要只写“暂无数据”。
- 页面级错误显示在顶部，保留“重试”按钮。

## 交互规范

- Hover：优先改变背景和边框，不让元素发生明显位移。
- Transition：颜色、阴影、展开等控制在 150–250ms，使用 `ease`；不要使用弹跳动画。
- 展开 / 收起：高度 + 透明度过渡，时长约 200ms。
- 列表新增：从上方 8px 淡入；删除：向右 20px 淡出。
- 焦点：所有输入框和主要按钮必须有 Sky 色 ring；键盘操作也能识别当前位置。
- 读取行为：查看 Cookie 或 Bridge 采用只读弹窗，不在查看态混入编辑控件。
- 长列表：优先左树 + 右详情，卡片网格保持两列以上；避免“每条记录一整行上下堆叠”导致滚动过长。

## 深色模式

- 使用 `dark` class 切换，不单独维护另一套布局。
- 浅色 `white / slate-50 / slate-100` 对应深色 `slate-900 / slate-950/50 / slate-950`。
- 边框从 `slate-200` 降到 `slate-800`，正文从 `slate-800` 提升为 `slate-100`。
- 深色模式的主色使用更亮的文字色（如 `sky-400`），不要把浅色的深蓝直接搬过去。
- 保证代码面仍为深色，不反转成白底。

## 禁止项

- 不使用渐变作为常规背景或主按钮。
- 不使用超过两层的卡片嵌套。
- 不把所有按钮做成胶囊形；这里以 `rounded-lg` 为默认。
- 不使用超过 24px 的页面标题，也不使用全大写中文标题。
- 不用颜色替代文本和图标表达状态。
- 不在一处同时放多个同等级主按钮。
- 不因“好看”增加自动轮播、无意义动效、实时刷新或大面积数据图表。

## 新项目落地清单

1. 先定义页面背景、Surface、输入框、按钮、Toast 五类基础样式。
2. 管理类页面优先采用“左导航 + 主内容”骨架；轻量工具使用 460px 左右 Popup。
3. 新页面必须有标题、简短描述和明确的空状态 / 错误状态。
4. 业务色先复用 Sky、Emerald、Amber、Violet、Red，不新增自定义颜色。
5. 每个异步操作提供加载、成功、失败反馈；危险操作提供确认。
6. 同时检查浅色和深色模式、窄屏、长文本、空数据和禁用状态。
7. 提交前确认没有渐变、过重阴影、无标题图标按钮、无提示的危险操作或无限拉长的单列列表。

## 给 AI / 开发者的复用指令

在其他项目需要延续本风格时，可直接附上下面这段：

```text
请遵循 Work DevTools 工作台 UI：Slate 中性色页面和白色 Surface，Sky 仅用于主操作和选中态；业务语义分别使用 Emerald、Amber、Violet、Red。管理页采用 248px 左导航和清晰页面标题，内容用 rounded-2xl 的轻边框白卡片；内部信息块用 rounded-xl 的 slate-50 面。页面级纵向相邻独立模块统一使用 8px（`mb-2`、`space-y-2` 或响应式网格 `gap-y-2`），卡片内部和表单字段保持各自信息密度。输入框为浅灰底、Sky focus ring；主按钮 Sky，危险操作 Red。支持完整深色模式。禁止渐变、重阴影、营销页式大标题、胶囊按钮泛滥和无意义动效。异步操作必须有加载、成功、失败反馈，查看态保持只读。
```
