# Work DevTools v1.0.2

发布日期：2026-08-07

`1.0.2` 为 Cookie Injector 和常用开发地址统一独立 JSON 弹框编辑能力，在保留结构化管理界面的同时，提升批量修改、校验和键盘编辑体验。

## 新增功能

- Cookie Injector 数据管理和常用开发地址页面均保留单独的“JSON”按钮，点击后在独立居中弹框中编辑对应工具数据。
- JSON 编辑器升级为 CodeMirror 6 并采用官方 One Dark 主题，支持语法高亮、行号、折叠、搜索、撤销/重做、自动换行、Tab 缩进和 JSON 语法诊断。
- JSON 弹框提供格式化、还原、取消和保存操作，并区分语法错误与 Cookie Injector、项目、环境、页面、URL、重复名称及默认环境等业务错误。
- 保存继续使用二次覆盖确认；关闭、取消、Escape 和点击蒙层统一提供未保存修改确认。

## 调整内容

- Cookie Injector 数据管理和常用开发地址始终保留结构化管理界面，不再提供“结构化 / JSON”整页模式切换。
- 两个 JSON 弹框分别只接收并保存 `tools.cookieInjector` 和 `tools.devAddresses`，不改变工作区根结构、存储键、导入导出或 WebDAV 数据格式。
- 两个领域弹框复用统一的 CodeMirror 编辑器底座，校验与保存逻辑仍保持各自工具边界。
- CodeMirror 资源改为弹框打开时按需加载，只使用扩展内本地拆分 chunk，不依赖 CDN、Worker 或远程资源。
- GitHub Release 继续复用版本 Markdown，但发布时不再展示仅供仓库追溯的“验证结果”小节。
- README 和相关回归测试同步更新为独立 JSON 弹框流程。

## 问题修复

- 修复项目和页面弹框中拖拽或选择文字后在蒙层松开鼠标时，可能误关闭弹框的问题。

## 升级注意事项

- 本版本没有数据迁移，现有常用开发地址、Cookie Injector、导入导出和 WebDAV 数据保持兼容。
- 更新扩展后重新打开管理页，即可在 Cookie Injector 数据管理和常用开发地址页面使用 JSON 弹框。

## 验证结果

- `yarn test`：64 项全部通过。
- `yarn build`：通过，成功生成 Chrome MV3 生产构建并确认 CodeMirror 资源保持按需拆分。
- `git diff --check`：通过。

## 安装方法

1. 从 GitHub Releases 下载 `work-devtools-1.0.2-chrome.zip`。
2. 解压 ZIP 文件。
3. 打开 Chrome 扩展管理页并开启开发者模式。
4. 点击“加载已解压的扩展程序”，选择解压后的目录。
