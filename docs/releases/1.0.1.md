# Work DevTools v1.0.1

发布日期：2026-08-05

`1.0.1` 新增常用开发地址工具，通过项目、环境和页面 path 的分层维护减少重复拼接地址，并为所有一级工具补充扩展图标右键直达入口。

## 新增功能

- 新增“常用开发地址”一级工具，支持维护项目名称、多个环境域名、默认环境、Wiki、备注和常用页面 path。
- 新建项目默认包含“健康检查 /health”；页面地址支持按默认环境组合后复制或新标签跳转，Wiki 支持复制或打开。
- 环境地址支持端口、基础 path、查询参数和锚点；项目详情使用平铺单选项切换默认环境。
- 一级工具只有一个功能页面时隐藏顶部 Tab 栏。
- 扩展图标右键菜单新增 Cookie Injector 和常用开发地址入口，可直接打开对应设置页。
- 管理页新增白名单 `nav` 参数，刷新后保留当前工具页面。

## 调整内容

- Work DevTools 根数据版本升级到 2，新增 `tools.devAddresses`；本机存储、导入导出和 WebDAV 同步统一覆盖新工具。
- Cookie Injector 的“JSON”编辑器仅展示并保存 `tools.cookieInjector`，不再暴露整个工作台根数据。
- 1.0.0 数据缺少常用开发地址时自动补为空数据，Cookie Injector 数据保持不变。
- 修复 1.0.0 根数据因缺少 `devAddresses` 被误判为无效、导致 Cookie Injector 数据管理显示为空的问题。
- 覆盖导入会重建项目、环境和页面 ID；合并导入保留本机同名数据并追加缺少内容。
- Popup 版本号改为读取扩展 Manifest，避免显示版本与构建版本不一致。

## 升级注意事项

- 更新后会申请 `contextMenus` 权限，用于在扩展图标右键菜单中展示工具入口。
- 首次读取 1.0.0 数据时会自动补充空的 `tools.devAddresses` 并将根数据版本更新为 2，无需手动迁移。

## 安装方法

1. 从 GitHub Releases 下载 `work-devtools-1.0.1-chrome.zip`。
2. 解压 ZIP 文件。
3. 打开 Chrome 扩展管理页并开启开发者模式。
4. 点击“加载已解压的扩展程序”，选择解压后的目录。
