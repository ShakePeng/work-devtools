# Work DevTools v1.0.0

发布日期：2026-08-05

`1.0.0` 将原 Cookie Injector 扩展升级为可继续承载多个开发工具的 Work DevTools 工作台，并完成统一数据结构、工具导航和自动发布流程。

## 新增功能

- 新增 Work DevTools 管理工作台，Cookie Injector 作为首个一级工具入口。
- 新增 Cookie 预设、Bridge 预设和设备UA预设管理页面。
- 新增 Cookie、Bridge Mock 和设备配置注入能力。
- 新增 JSON 全量导入导出和 NAS WebDAV 手动同步。
- 新增 GitHub Actions 自动发布流程，推送 `v1.0.0` 标签后自动测试、打包并创建 Release。

## 调整内容

- Cookie Injector 的四个功能调整到内容区顶部 Tab，点击左侧工具入口默认进入数据管理。
- 本机存储、JSON 备份和 WebDAV 统一使用 Work DevTools 根数据结构，工具数据位于 `tools.cookieInjector`。
- `version` 和 `updatedAt` 仅保留在工作台根节点。
- 扩展名称、包名、页面标题、日志和同步文件统一使用 Work DevTools 品牌。
- GitHub Actions 和项目运行环境统一使用 Node.js 22.13.0 及以上版本。
- 删除 MemberId Cookie 查询入口、后台消息和加密依赖。

## 升级注意事项

- 旧版 Cookie Injector 本机数据会自动迁移到 `work_devtools.data`，成功后清理旧本机键。
- Popup 人员展开状态会迁移到新的 Cookie Injector 命名空间。
- 旧 `cookie-injector-sync` WebDAV 连接会被重置，不读取、迁移或删除旧远端同步文件。
- 新的 WebDAV 同步文件为 `work-devtools-sync.json`，内容包含明文 Cookie，请限制同步目录权限。

## 安装方法

1. 从 GitHub Releases 下载 `work-devtools-1.0.0-chrome.zip`。
2. 解压 ZIP 文件。
3. 打开 `chrome://extensions/` 并开启开发者模式。
4. 点击“加载已解压的扩展程序”，选择解压后的目录。
